ClosedTab

A shared record for human and agent teams: what you asked for, what the agent did, and what it understood the instruction to be.

$ npm i -g closedtabnpmGitHubWrite-up

When you build fast with agents, the reasoning behind each decision disappears. A week later you can’t say what you asked for or what the agent did.

ClosedTab writes an Agent Action Record for each piece of agent work, in six parts: Intent, Action, Judgment, Deviation, Consequence and Change. check scores a record. reconcile lines it up against a machine trace and reports where the record claims more than the trace shows.

Private fences keep sensitive text in a gitignored store, and an unclosed fence fails closed. Every agent run on my sites ends with a record in the repo, and Vloora requires one for every handoff.

Node.js on npm (0.5.0), closedtab-mcp stdio server, Agent Skill
